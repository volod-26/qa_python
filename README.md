# Выполненные тесты

В рамках проекта были написаны unit-тесты для класса `BooksCollector` с использованием pytest.

### Список тестов:

- **add_new_book** — проверка добавления новых книг (валидные/невалидные названия, дубликаты)
- **set_book_genre** — проверка установки жанра книги (валидный/невалидный жанр)
- **get_book_genre** — проверка получения жанра книги
- **get_books_with_specific_genre** — проверка фильтрации книг по жанру
- **get_books_genre** — проверка получения словаря книг
- **get_books_for_children** — проверка, что книги с возрастным рейтингом не попадают в детский список
- **add_book_in_favorites** — проверка добавления книг в избранное
- **delete_book_from_favorites** — проверка удаления книг из избранного
- **get_list_of_favorites_books** — проверка получения списка избранных книг
